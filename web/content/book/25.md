All-pairs shortest paths: the n×n distance matrix. Run Dijkstra from every vertex (O(VE + V² lg V)) or Bellman-Ford from every vertex (O(V²E)) — or use one of three matrix-flavored algorithms that exploit the problem's DP structure.

## 25.1 Shortest paths as matrix multiplication

Define the "product" L·W with min and + in place of + and ×: `(L·W)[i,j] = min_k (l[i,k] + w[k,j])`. L^(m) then holds shortest paths using ≤ m edges. Naively computing L^(n−1) costs Θ(n⁴); repeated squaring of the product gets Θ(n³ lg n). The point isn't speed — it's recognizing that relaxation over all pairs *is* a semiring matrix product, the same shape as Floyd-Warshall with a different loop order.

## 25.2 Floyd-Warshall — Θ(n³), the classic

The DP with the cleanest state in the book: `d^(k)[i,j]` = shortest i→j path whose *intermediate vertices* all come from {1..k}. Then

```
d^(k)[i,j] = min( d^(k-1)[i,j],  d^(k-1)[i,k] + d^(k-1)[k,j] )
```

— either the path avoids k, or it passes through k exactly once (k's intermediate set excludes k). Loop k outermost; in-place storage works because d^(k)[i,k] = d^(k−1)[i,k]. Θ(n³) time, Θ(n²) space, tiny constants, negative edges fine (no negative cycles). Three nested loops, 25 lines — the highest value-per-line algorithm in the book for grid-based LeetCode problems (any "min cost path with moves between all cells" n≤200 smells like this).

Transitive closure is the same DP with OR/AND: T^(k) = T^(k−1) OR (T[i,k] AND T[k,j]).

## 25.3 Johnson's — for sparse graphs

Reweighting: compute potentials h(v) via one Bellman-Ford run (super-source), define ŵ(u,v) = w(u,v) + h(u) − h(v). All ŵ ≥ 0, and every path's weight shifts by the same h-dependent constant — so shortest paths are unchanged. Now run Dijkstra from each vertex on the nonnegative reweights: O(VE + V² lg V). Sparse graphs make this beat Floyd-Warshall's Θ(n³) (E ≪ V²), and the reweighting trick itself shows up elsewhere (e.g., difference constraints, Ch. 24.4: systems of difference constraints ⟷ shortest paths in a constraint graph).
