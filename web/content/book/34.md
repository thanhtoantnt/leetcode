The chapter that explains why some problems have no known good algorithm — and how to *prove* your problem is one of them, so you stop looking and start approximating (Ch. 35) or restricting (small n, backtracking — the `backtracking/` folder's niche).

## P, NP, and what "hard" means

- **P**: decidable in polynomial time.
- **NP**: verifiable in polynomial time given a certificate (a proposed solution checks out fast). Equivalently: polynomial time on a nondeterministic machine. Note P ⊆ NP.
- **NP-complete**: in NP, and every NP problem polynomial-time *reduces* to it. If any NPC problem is in P, then P = NP.

The near-misses that build intuition: Euler tour (visit every *edge* once) is O(E); Hamiltonian cycle (every *vertex*) is NP-complete. 2-CNF satisfiability is P; 3-CNF is NP-complete. Shortest path is P; longest *simple* path is NP-hard (Chapter 15's counterexample, explained). Small edits to a problem statement jump complexity classes — that's the chapter's recurring lesson.

## Reductions — the machinery

A ≤_P B: a poly-time transform turning instances of A into instances of B, preserving yes/no. To prove B NP-complete: (1) B ∈ NP, (2) some known NPC problem reduces to B. Cook-Levin bootstraps everything with CIRCUIT-SAT; then the chapter chains: SAT → 3-CNF-SAT → CLIQUE → VERTEX-COVER → HAM-CYCLE → TSP, and 3-CNF-SAT → SUBSET-SUM.

The reductions to actually know:

- **CLIQUE ↔ VERTEX-COVER** via complements: a k-clique in G ⟺ a (|V|−k) vertex cover in the complement graph.
- **HAM-CYCLE → TSP**: complete graph, cost 0 on G's edges / 1 elsewhere, budget 0 — a tour of cost 0 is exactly a Hamiltonian cycle.
- **3-SAT → SUBSET-SUM**: numbers built column-wise (variables and clauses as digit positions) — the bridge from logic to arithmetic that makes subset-sum/`dynamic/0416`-style problems provably hard in general.

## How to use it

When your own problem smells exponential: try reducing a known NPC problem to it (a sketch suffices for interviews). If it works, pivot: small-n backtracking with pruning, DP on a restricted parameter, or an approximation with a provable ratio — the next chapter.
