Single-source shortest paths with weights: the relaxation framework, then three algorithms differing only in edge-weight assumptions and order of processing.

## The framework

Every algorithm here maintains estimates `v.d ≥ δ(s,v)` and predecessors, improving them by **relaxation**: for edge (u,v), if `u.d + w(u,v) < v.d`, update. Properties proved once and reused: upper-bound (d only drops), convergence (relaxing along shortest paths sticks), path-relaxation, and — the structural fact underneath everything — **subpaths of shortest paths are shortest paths** (optimal substructure, the DP license).

Negative weights break nothing by themselves; **negative-weight cycles reachable from s** make the problem ill-posed (distance −∞). Each algorithm handles them differently.

## 24.1 Bellman-Ford — O(VE), tolerates negatives

Relax *all* edges, V−1 times. Any shortest path has ≤ V−1 edges, and each full pass guarantees one more edge of every shortest path is correct. A V-th pass that still improves something proves a reachable negative cycle. Slow but general — and the engine inside modern routing (distance-vector protocols) and some DP formulations.

## 24.2 DAG shortest paths — O(V+E)

Topologically sort (Ch. 22), relax edges in order. No cycles means each vertex is final when reached. Handles negative weights free — the absence of cycles removes the problem. This is the "process states in dependency order" trick, i.e., DP on a DAG (Ch. 15's subproblem graph, materialized).

## 24.3 Dijkstra — O(E + V lg V), nonnegative only

The famous one: greedily finalize the unsettled vertex with smallest d, relax its edges, repeat. The min-priority queue (Ch. 6) holds the frontier; correctness needs nonnegative weights exactly so that finalizing the smallest-d vertex is safe (a shorter path through an *unsettled* vertex can't exist — any detour starts with an edge ≥ 0).

The proof is a loop invariant in Chapter 2's style, and the structure is Prim's twin: grow a set of finalized vertices by cheapest frontier edge. Fibonacci heaps make it O(E + V lg V); binary heaps O((V+E) lg V) — the practical default (`graphs/` Dijkstra problems).

## Which algorithm when

unweighted → BFS (Ch. 22); nonnegative weights → Dijkstra; negative edges but no reachable negative cycle → Bellman-Ford (or DAG-shortest-paths if the graph is acyclic); negative cycle detection → Bellman-Ford's extra pass.
